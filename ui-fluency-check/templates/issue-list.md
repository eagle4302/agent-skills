## 路由規則

| 路由 | 代表意義 | 下一步 |
|---|---|---|
| Design | 版面、文案、動線、互動規則要改 | 改 SVG 與 `UI_SPEC.md`，重新核准 |
| Implementation | 設計不變，程式要修 | 開實作票，附量測數據 |
| Data | 欄位、值、空狀態資料錯 | 修 fixture 或資料來源 |
| Environment | DPI、字型、輸入、網路、機器 | 修測試環境或列為已知限制 |

## 分級規則

- Blocker：任務無法完成、資料錯誤或遺失、崩潰、安全相關狀態不清。
- Major：可完成但迷路、繞路、死路，或明顯手感問題。
- Minor：拖慢但未改變結果。
- Cosmetic：只影響觀感。
