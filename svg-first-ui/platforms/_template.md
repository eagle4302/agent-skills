# 平台轉換文件模板（新增平台時複製這份）

> 平台不是白名單。`platforms/` 底下的檔案只是已寫好的加速器；選定平台沒有對應檔案時，用這份模板加官方文件寫一份。
> 不要拿別的平台的規則硬套；也不要把設計改成某一家才有的樣子。

## 使用方式

1. 先確認平台與版本（框架版本、工具鏈版本），寫在標題下一行。
2. 只寫「有官方依據」的內容；查不到就標「待查」，不要憑印象。
3. 三件事一定要有：版面系統、主題／token 機制、截圖方式。缺一項就不能拿來做 Phase 5。
4. 從 `SKILL.md` 的 Phase 4／Phase 5 需求反推要寫哪些段落。
5. 寫完在 `SKILL.md` 的檔案表加一列。

## 1. 尺寸與 DPI

- 設計 px 對應到平台的什麼單位？縮放由誰處理？
- 固定截圖尺寸與縮放倍率怎麼設定？
- 觸控／滑鼠最小目標尺寸怎麼表達？

## 2. 版面

| SVG 結構 | 平台寫法 |
|---|---|
| 固定頂部工具列 | <layout 容器> |
| 左右分欄 | <layout 容器＋尺寸分配> |
| 等寬卡片列 | <grid 或 stretch> |
| 清單／表格 | <資料驅動控制項> |
| 浮層 | <overlay／popup 機制> |

- 平台的版面系統是什麼？哪些屬性用來分配剩餘空間？
- 哪些寫法會破壞版面（例如絕對座標、在版面容器內直接寫固定尺寸）？
- 最小視窗寬度與重排規則。

## 3. 設計變數 → 平台主題

- token 要放在哪裡（資源字典、singleton、theme 物件、CSS 變數）？
- 深／淺主題怎麼切換？token 只換值、元件不改。
- 內建控制項的預設樣式要怎麼覆寫，才不會每個畫面各自調？

## 4. 元件與重用

- `<g id>` 對應到哪種元件型別與命名規則？
- `<use>` 元件怎麼實作成可重用元件？
- 清單與表格怎麼用資料驅動渲染，而不是複製 row？

## 5. 狀態

- 狀態怎麼表達（enum、state 物件、屬性）？
- 載入中、空資料、錯誤、離線、無權限、停用各自用什麼容器／模板切換？
- 切換時怎麼讓版面不跳動？

## 6. 資料與假資料

- 資料繫結機制與型別宣告方式。
- 假資料放哪裡、怎麼在開發期切換狀態。
- 有沒有設計師預覽模式（design-time data）？

## 7. 字型與圖示

- 中文字型怎麼指定？數值要不要等寬字？
- SVG 圖示是原生支援、需要套件，還是要轉成 path？
- 圖示顏色怎麼跟隨主題？

## 8. 截圖與比對

- 怎麼在固定尺寸、固定縮放下截圖？
- 有沒有內建或官方的無頭截圖方式？
- 互動驗證用什麼工具？
- 與核准 PNG 並排、差異報告放哪裡。
