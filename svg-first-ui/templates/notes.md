## 狀態清單

| 狀態 | 何時出現 | 畫面顯示 | 檔案 |
|---|---|---|---|
| 正常 | 有資料且連線正常 | 完整版面 | `<screen>_hifi_v1.svg` |
| 載入中 | 首次載入、切換設備 | 骨架屏／spinner，版面不跳動 | `_loading.svg` |
| 空資料 | 查詢無結果 | 插圖＋說明＋主動作 | `_empty.svg` |
| 錯誤 | API 失敗 | 錯誤訊息＋重試 | `_error.svg` |
| 警報 | 有未確認警報 | 紅色標記、警報列置頂 | `_alarm.svg` |
| 離線 | 裝置斷線 | 灰化、最後更新時間、重連狀態 | `_offline.svg` |
| 無權限 | 角色不足 | 遮罩＋申請權限說明 | `_no-permission.svg` |
| 停用 | 功能關閉或維護 | 控制項停用＋原因 | `_disabled.svg` |
